# Akshay Pujari - Portfolio

A modern, responsive portfolio website built with Next.js, Tailwind CSS, and Framer Motion.

## Features

- 🎨 Nova9.ai inspired design with dark theme
- ⚡ Next.js with App Router for performance
- 🎭 Smooth animations with Framer Motion
- 📱 Fully responsive design
- 🚀 Optimized for GitHub Pages deployment

## Setup

1. Install dependencies:
```bash
npm install
```

2. Run development server:
```bash
npm run dev
```

3. Build for production:
```bash
npm run build
```

## Deployment to GitHub Pages

1. Build the project:
```bash
npm run build
```

2. The `out` folder contains the static files ready for deployment

## Sections

- Hero - Animated introduction
- Resume - Professional experience timeline
- Projects - Featured work with Bento Grid layout
- Skills - Technical capabilities
- Contact - Get in touch form and social links
